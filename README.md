# AgriSense AI

## One-Line Description
An AI-powered agriculture intelligence platform that helps farmers make data-driven farming decisions.

## Tech Stack
- Frontend: Next.js
- Styling: Tailwind CSS
- Backend: Express.js
- Database: MongoDB
- Authentication: JWT + bcrypt
- AI Integration: Gemini API
- Deployment: Vercel + Render
